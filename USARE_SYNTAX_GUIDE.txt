USARE v2.0 - Ultimate Stealth And Reconnaissance Engine
=====================================================

USARE is a specialized network reconnaissance tool designed to bypass Next-Generation Firewalls (NGFW), ML-driven Intrusion Prevention Systems (IPS), and advanced SOC monitoring by strictly targeting single, highly defended external hosts.

Unlike Nmap, which prioritizes speed and enterprise-wide discovery, USARE prioritizes absolute silence and temporal decorrelation.

BASIC SYNTAX
------------
usare [OPTIONS] -t <target_ip>

TARGET SPECIFICATION:
  -t, --target <IP>       The single IPv4 address to target. USARE does not
                          support bulk subnet sweeps by default to prevent
                          accidental acoustic signatures.

PORT SPECIFICATION:
  -p, --ports <range>     Standard list: 80,443,3389
                          Standard range: 1-1000
                          If omitted, scans a default top 100 list. Note: USARE
                          randomly shuffles this list internally to prevent
                          sequential port scanning signatures.

STEALTH AND EVASION OPTIONS (The Core of USARE)
-----------------------------------------------
  --ebpf                  [LINUX ONLY] Enables the eBPF kernel module. This
                          silently drops RST packets generated by the host OS
                          before they reach the wire, preventing the target
                          from realizing a raw socket scan is occurring.
                          (Requires root).
                          
  --ghost                 Enables Gaussian-distributed temporal delays between
                          probes. Defeats threshold-based rate-limiting alerts.
                          USARE calculates the wait time dynamically based on
                          the 'heat' profile of the target.
                          
  --cold-start            [PASSIVE] Before sending a single packet, USARE will
                          sniff the local interface in promiscuous mode for
                          120 seconds. It captures legitimate background traffic
                          (e.g., your browser reaching out to Google) and
                          perfectly clones the OS TTL and TCP Window size to
                          blend in perfectly with genuine host traffic.
                          
  --decoys <number>       Generates N synthetic decoy packets with spoofed
                          source IPs for every 1 real probe. Spoofed IPs are
                          geographically bound to the target's subnet to prevent
                          BGP routing drops.
                          
  --fragment <STRAT>      Breaks the TCP header across multiple IP fragments.
                          - 'standard': 8-byte standard IP fragmentation.
                          - 'overlap': Injects intentional overlapping offsets
                            forcing the IDS to guess the reassembly policy.
                          - 'reverse': Sends fragments out of order.
                          - 'ttl': Evades hop-count monitoring by setting
                            invalid TTLs on fragments.

  --lte                   Overrides the `--ghost` timer with realistic 4G/5G
                          mobile network latencies (120ms - 800ms jitter) to
                          camouflage the scanner as a mobile phone user.

  --desync                Injects a 3-packet TCP burst with a corrupted-checksum
                          RST between the SYN and the real probe. Stateful
                          firewalls read the RST and stop tracking the flow, but
                          the target drops it because of the bad checksum. The
                          real probe slips through unmonitored. (Requires root).

RECONNAISSANCE MODULES
----------------------
  --full                  Runs all available modules sequentially.
  -sV                     Enables Advanced Service Probes (Nmap parity). Sends
                          specific binary handshakes (RDP, SMB, MySQL) instead
                          of just HTTP GET requests.
  --jarm                  Extracts the JARM TLS fingerprint of the target server
                          without completing the SSL handshake. Identifies cobalt
                          strike servers, customized nginx builds, and WAFs.
  --vuln                  Checks identified services against the backend SQLite
                          NVD database for known CVEs.

POWERFUL COMBINATIONS
---------------------

1. The "Maximum Stealth" Profile (Ghost in the Wire)
   sudo ./usare.sh -t 1.2.3.4 -p 22,80,443,3389 --ebpf --cold-start --ghost --lte --fragment overlap --decoys 10 --full
   
   Why it works:
   - `--cold-start` ensures the packets look identical to your OS.
   - `--ebpf` ensures your OS doesn't betray you with RST packets.
   - `--fragment overlap` breaks the deep packet inspection capabilities of Palo Alto/Fortinet firewalls.
   - `--lte` + `--ghost` ensures the packets arrive at intervals that look like a human browsing on a phone.
   - `--decoys 10` floods the SOC logs with 10 fake IPs for every 1 real IP, making attribution impossible.

2. The "Nmap Parity" Speed Profile (No Evasion, Pure Speed)
   sudo ./usare.sh -t 1.2.3.4 -p 1-10000 -sV --no-ghost
   
   Why it works:
   - Disabling `--ghost` activates the new Python `asyncio` engine. USARE will blast the target concurrently, bypassing the Global Interpreter Lock (GIL), matching Nmap's raw socket speed. `-sV` sends the advanced binary handshakes to accurately fingerprint databases and enterprise services.

OUTPUT AND LOGGING
------------------
  --format <json/csv/html> Exports the final scan results to the specified
                          format in the `logs/` directory. All data is

ADVANCED
--------
  --top-ports <N>         Scan the top N most common ports from USARE's
                          built-in service dictionary (170+ services).

  --quiet                 Suppress the Rich terminal UI and output only
                          machine-readable JSON. Useful for piping.

  --diff <file.enc>       Compare the current scan results against a previous
                          encrypted scan. Highlights new, closed, and changed
                          ports for change monitoring.

  --resume                Resume an interrupted scan from the `.usare_session`
                          file saved by Ctrl+C handling.

  --source-masq           Use source port mimicry (DNS/53, HTTPS/443, NTP/123)
                          to bypass firewalls that whitelist "established"
                          connections.

  --desync                Injects a 3-packet TCP burst with a corrupted-checksum
                          RST between the SYN and the real probe. Stateful
                          firewalls read the RST and stop tracking the flow, but
                          the target drops it because of the bad checksum. The
                          real probe slips through unmonitored. Now includes:
                          • TTL-expiry variant (RST expires before target)
                          • State table exhaustion (half-open SYN flood)
                          • Data desync (overlapping TCP segments)
                          (Requires root).

DEEP EVASION (Phase 9)
----------------------
  --flow-morph <profile>  Wrap scan probes inside statistically realistic
                          browser traffic flows. Profiles: chrome, firefox,
                          curl, winupdate. Generates cover packets matching
                          real inter-packet timing, byte counts, and flow
                          teardown patterns. Defeats carrier-level DPI that
                          operates on flow shape rather than individual packets.

  --tunnel <https|dns>    Encapsulate probes inside legitimate protocol traffic.
                          HTTPS: wraps probes in real TLS sessions on port 443.
                          DNS: encodes probe data in DNS query subdomains.
                          From the carrier's perspective, this is normal
                          browsing or DNS resolution traffic.

  --distributed <file>    Distribute the scan across multiple nodes defined in
                          a JSON config file. Each node scans a disjoint port
                          subset from a different ASN. Results are merged
                          client-side. No single source is recognizable as a
                          scanner. See distributed_nodes_example.json.

  --baseline <minutes>    Generate legitimate HTTPS/DNS/NTP background traffic
                          for N minutes before scanning begins. Establishes a
                          behavioral baseline at the carrier level so scan
                          traffic blends into an established pattern. Uses
                          gradual ramping to naturally transition into scanning.

STANDALONE SCAN MODES (Firewall Bypass)
----------------------------------------
  --fin                   FIN scan (Nmap -sF equivalent). Sends FIN packets
                          instead of SYN. Closed ports send RST back; open
                          ports silently drop the FIN (RFC 793 behaviour).
                          Bypasses stateful firewalls that only inspect SYN.
                          Result: CLOSED (RST), OPEN|FILTERED (no reply),
                          FILTERED (ICMP unreachable).

  --maimon                Maimon scan (Nmap -sM). Sends FIN+ACK probes.
                          Named after Uriel Maimon -- susceptible BSD stacks
                          (FreeBSD, older Cisco IOS) drop FIN+ACK to open
                          ports instead of RST, making open ports visible.

  --custom-flags <hex>    Send any TCP flag bitmask and observe responses.
                          Examples: 0x00=NULL, 0x29=FIN+PSH+URG, 0xC2=ECN.
                          Use --custom-flags-name <label> to tag results.

  --desync-mode <variant> TCP desync variant (requires --desync):
                          checksum     (default: corrupted RST checksum)
                          ttl-expiry   (RST with short TTL expires en-route)
                          state-exhaust (flood firewall state table first)
                          data-inject  (overlapping TCP segment injection)
                          adaptive     (auto-select based on traceroute data)

NEW EVASION TECHNIQUES (Phase 36-38)
-------------------------------------
  --ts-forge <OS>         Forge TCP timestamps to impersonate any OS clock.
                          Defeats p0f, Zeek, and other passive OS fingerprinters.
                          Options: linux_modern (1000Hz), linux_legacy (250Hz),
                          windows10 (100Hz), macos (1000Hz), freebsd (1000Hz),
                          solaris (100Hz), cisco_ios (100Hz).
                          Each target gets its own independent forged clock epoch
                          to prevent cross-session timestamp correlation.

  --icmp-covert           ICMP LSB steganography covert channel.
                          Embeds probe data inside Windows ping payload LSBs.
                          Indistinguishable from normal ICMP echo traffic to DPI.
                          Use --icmp-covert-bits 1|2|4 to tune entropy vs capacity.

  --icmp-egress-map       Map egress firewall rules via ICMP Unreachable codes.
                          Sends UDP probes, reads ICMP Type 3 responses.
                          Zero TCP/UDP connections established -- no firewall state.
                          Reveals: open, closed, net-unreachable, host-unreachable,
                          and ACL-drop (admin-prohibited) policies.

  --gre-tunnel            Wrap probes in GRE (IP protocol 47) encapsulation.
                          L4 stateful firewalls cannot inspect inside GRE.
                          Use --gre-relay <IP> for a cooperative exit node that
                          decapsulates and forwards to the target (bidirectional).
                          Without relay, probes go direct -- one-way if GRE passes.

  --igmp-enum             IGMP multicast host discovery. Sends IGMPv2 General
                          Query to 224.0.0.1 (all-hosts). Every RFC-compliant
                          IPv4 host MUST respond. Zero unicast traffic generated.
                          Invisible to IDS systems monitoring only unicast.
                          Fingerprints OS/role from multicast group memberships:
                          224.0.0.251=mDNS (Apple/Linux), 224.0.0.252=LLMNR (Windows),
                          239.255.255.250=UPnP (IoT), 224.0.0.9=RIP (router).

  --syn-cookie-probe      Detect SYN cookie mode and infer server posture.
                          Analyses ISN top-5-bit patterns from SYN-ACK responses.
                          Linux cookies encode: t (time slot) + MSS index in ISN.
                          Reveals: is server under SYN flood? Which OS? MSS used?

  --vlan-hop              802.1Q VLAN double-tagging attack. Requires local
                          Ethernet access to a trunk port's native VLAN.
                          Outer tag = native VLAN (stripped by switch).
                          Inner tag = target VLAN (delivered to VLAN hosts).
                          Use --vlan-id <outer> and --vlan-target <inner>.
                          ONE-WAY: replies don't return. Use --gre-relay or
                          --igmp-enum first to discover targets on inner VLAN.

  --ipv6-discover         IPv6 host discovery via ICMPv6, NDP Neighbour
                          Solicitation, and all-nodes multicast (ff02::1).
                          Every IPv6 host MUST respond to multicast ping.
                          Use --ipv6-prefix <PREFIX/LEN> to also ping-scan
                          a specific /64 prefix randomly.

  --smb-null              SMB null/anonymous session enumeration.
                          Connects to port 445 with empty credentials.
                          On misconfigured systems: enumerates share names,
                          reads OS version, server name, domain/workgroup.
                          Requires SMBv1 or SMBv2 with guest access enabled.

  --honeypot-detect       Analyse all scan results for honeypot indicators.
                          Checks: banner signatures (Cowrie, Honeyd, OpenCanary),
                          port count explosion, latency uniformity (CV score),
                          TTL inconsistency, impossible service combos,
                          echo service (port 7), OS/service mismatches.
                          Outputs verdict with per-indicator confidence scores.

OUTPUT CONTROL
--------------
  --output-dir <DIR>      Directory for all exported reports (default: logs/).
                          JSON, CSV, HTML, and XML all go here.

  --module-timeout <sec>  Timeout for post-scan modules (banner grab, cert,
                          service detect). Defaults to 3x --timeout.
                          Lets you run aggressive scans with slow banner grabs.

  --nvd-api-key <KEY>     NVD API key for vulnerability mapping.
                          Without key: 5 requests/30s. With key: 50 requests/30s.
                          Get free key at: https://nvd.nist.gov/developers/request-an-api-key

  --zombie-port <PORT>    Port to probe the zombie host on during idle scan.
                          Default: 80. Should be a port on the zombie that
                          produces consistent IP ID increments.
